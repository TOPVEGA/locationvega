توثيق واجهات API

مرحباً بك في صفحة توثيق APIs الخاصة بمنصة python zone. جميع الواجهات متاحة للاستخدام مع أمثلة بسيطة.

📌 YouTube API

GET /api/youtube/search?q=python

يُستخدم للبحث عن فيديوهات على يوتيوب، يعيد قائمة بالنتائج مع روابط التشغيل.

📌 Spotify API

GET /api/spotify/playlist?id=37i9dQZF1DXcBWIGoYBM5M

يجلب بيانات قائمة تشغيل محددة من سبوتيفاي.

📌 Telegram API

POST /api/telegram/send-message

يرسل رسالة عبر بوت تليجرام، يحتاج إلى chat_id و text.

📌 Media API

POST /api/media/upload

رفع ملف وسائط (صورة، فيديو، صوت) ومعالجته.

ملاحظة: جميع الـ APIs تعمل عبر HTTPS وتدعم CORS، يمكنك تجربتها مباشرة من تطبيقك.
